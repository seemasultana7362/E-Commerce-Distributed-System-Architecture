🔧 MOST USEFUL COMMANDS:

Development:
  make dev              Start full environment (Docker)
  make build            Build Docker images
  make up               Start services
  make down             Stop services
  make logs             View all logs
  make clean            Remove containers & volumes

Testing:
  make health-check           Check service health
  make test-auth-register     Test user registration
  make test-auth-login        Test user login
  make test-products-list     Test product listing
  make test-categories        Test categories

Local Development (without Docker):
  make build-auth        Build auth service binary
  make build-product     Build product service binary
  make run-auth          Run auth service
  make run-product       Run product service

📊 API ENDPOINTS QUICK REFERENCE:

Authentication:
  POST   /api/v1/auth/register       - Register new user
  POST   /api/v1/auth/login          - Login user
  POST   /api/v1/auth/refresh        - Refresh token
  GET    /api/v1/auth/me             - Get current user
  POST   /api/v1/auth/logout         - Logout

Products:
  GET    /api/v1/products            - List products
  GET    /api/v1/products/{id}       - Get product
  GET    /api/v1/categories          - Get categories
  POST   /api/v1/products            - Create product (admin)
  PUT    /api/v1/products/{id}       - Update product (admin)
  DELETE /api/v1/products/{id}       - Delete product (admin)

❓ COMMON QUESTIONS:

Q: How do I start the services?
A: Run 'make dev' - it starts everything automatically

Q: What's the database password?
A: Default is 'postgres' for both auth and product DBs

Q: How do I test the API?
A: Use curl commands in QUICKSTART.md or use Postman

Q: How do I view logs?
A: Run 'make logs' or 'make logs-auth' / 'make logs-product'

Q: What's the JWT secret?
A: Change 'your-secret-key-change-in-production' in docker-compose.yml

Q: How do I stop everything?
A: Run 'make down' or 'make clean' to remove containers
